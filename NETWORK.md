# App Network

**Status:** backend application source, not a hosted Pages chat service. Chatty uses Spring Boot and WebSocket server-side components. Existing application code, theme work, and dependencies are unchanged.

[App Network Hub](https://sauravnrai.github.io/) · [This project in the catalog](https://sauravnrai.github.io/projects.html#chatty) · [Discovery](https://sauravnrai.github.io/discovery/)

## Browser tools
- [ASF Studio](https://sauravnrai.github.io/ASF/) — import and preview local CSV/JSON.
- [Analytics](https://sauravnrai.github.io/ASF-analytics/) — completeness, filtering, statistics and exports.
- [Visualizer](https://sauravnrai.github.io/ASF-visualizer/) — local charts and SVG export.

Discovery generates results locally; its optional email buttons open drafts and require the visitor to click Send. Browser-only tools are separate from this server project. Updated 2026-11-15.
